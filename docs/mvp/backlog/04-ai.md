# AI backend tickets

## BE-015 — Implement AI allowance accounting

**Owner:** Codex  
**Dependencies:** BE-005  
**Status:** pending

### Scope

- Implement monthly per-user usage with a configurable 100-call limit.
- Implement the separate application-wide monthly budget in integer micro-USD.
- Atomically reserve a conservative cost before provider work.
- Reconcile the reservation from returned usage and define compensation for work that is permanently
  rejected before provider acceptance.
- Fail closed when price configuration is missing or stale.

### Acceptance evidence

- Concurrency tests prove neither allowance can be overspent by racing requests.
- Boundary, rollover, reconciliation, and compensation cases are covered.

## BE-016 — Implement asynchronous AI request acceptance

**Owner:** Codex  
**Dependencies:** BE-015  
**Status:** pending

### Scope

- Implement quick-entry and owned-receipt-draft request endpoints.
- Validate disclosure-sensitive input, ownership, receipt state, idempotency, and both allowances.
- Transactionally create the request, consume/reserve allowance, and mark it for enqueue
  reconciliation.
- Submit to standard SQS and return `202` with a request ID.

### Acceptance evidence

- Tests cover duplicate submissions, mismatched idempotency bodies, quota/budget exhaustion, SQS
  failure, invalid receipt state, and cross-ledger attempts.

## BE-017 — Implement the DeepSeek worker and normalized drafts

**Owner:** Codex  
**Dependencies:** AWS-003, BE-016  
**Status:** pending

### Scope

- Implement the backend-only provider adapter with bounded input/output and total timeout.
- Prepare receipt derivatives without persisting them and remove image metadata.
- Request the versioned provider schema, then parse, validate, and semantically normalize the
  untrusted result.
- Store only the TallyNest-owned normalized draft and safe usage metadata.
- Use conditional state transitions so duplicate SQS delivery cannot repeat work.

### Acceptance evidence

- Fixture tests cover valid, ambiguous, missing, malformed, truncated, extra-field,
  unsupported-currency, timeout, and provider-failure responses.
- No test or log exposes raw prompts, receipt contents, provider output, or keys.
